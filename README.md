# Pleshanov Publisher Legal Pages

Static legal pages for the Pleshanov Publisher TikTok Developer app.

Pages after GitHub Pages is enabled:

- https://gamgid.github.io/pleshanov-publisher-legal/
- https://gamgid.github.io/pleshanov-publisher-legal/privacy.html
- https://gamgid.github.io/pleshanov-publisher-legal/terms.html

## Enable GitHub Pages

Open repository Settings, then Pages. Under Build and deployment, select:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Save and wait 1-2 minutes for the site to publish.
